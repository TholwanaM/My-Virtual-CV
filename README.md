 My Virtual CV

Overview

Welcome to my Virtual CV, an interactive portfolio website developed to showcase my academic journey, technical skills, projects, and passion for Information Technology.
This website provides an immersive digital experience that allows visitors to explore my background through smooth animations, modern user 
interface design, and interactive content. Every element was carefully designed to create a memorable first impression while demonstrating my front-end web development abilities.

Objectives

The primary goal of this project was to create a professional online portfolio that:
  - Presents my academic achievements and technical abilities.
  - Showcases personal and university projects.
  - Demonstrates my front-end development skills.
  - Provides recruiters with easy access to my CV, GitHub profile, LinkedIn profile, and contact information.
  - Creates a memorable and engaging user experience through modern web technologies.

Website Features

This portfolio includes a range of modern web development features, including:
  - Fully responsive design for desktop, tablet, and mobile devices.
  - Full-screen animated hero section.
  - Smooth scrolling and cinematic page transitions.
  - Hidden sliding navigation menu.
  - Interactive project showcase with detailed project information.
  - Animated buttons and hover effects.
  - Custom cursor interactions.
  - Dynamic gradient typography and colour transitions.
  - Glassmorphism-inspired interface elements.
  - Downloadable CV.
  - External links to GitHub, LinkedIn, and other professional platforms.
  - Modern accessibility and usability considerations.

Technologies Used

The project was developed using modern front-end web technologies, including:
  - HTML5
  - CSS3
  - JavaScript (ES6)
  - GSAP Animation Library
  - Lenis Smooth Scrolling
  - GitHub Pages

Website Structure

The portfolio is organised into several sections:
Home
  Introduces visitors with an animated hero section featuring my name and professional identity.

About
  Provides an overview of who I am, my interests, and my aspirations as an Information Technology student.

Education
  Highlights my academic background, qualifications, and learning journey.

Skills
  Showcases both technical and professional skills developed through coursework and personal projects.

Projects
  Displays selected projects with descriptions, technologies used, and links to source code or live demonstrations.

Contact
  Provides multiple ways for recruiters and collaborators to connect with me.


Design Philosophy

  The visual design focuses on simplicity, elegance, and usability.
  Inspired by contemporary editorial layouts and abstract artwork, the interface combines clean typography, organic shapes, subtle animations, and warm accent colours to create a professional yet distinctive identity.
  Rather than relying on conventional portfolio layouts, the website aims to provide a modern browsing experience that reflects creativity while maintaining a strong focus on readability and accessibility.

Purpose

  This portfolio serves as my digital curriculum vitae and professional showcase. It reflects not only my academic progress but also my commitment to continuous learning, problem-solving, and creating engaging digital experiences.
  As I continue my studies and gain new experience, this portfolio will evolve to include additional projects, certifications, technical skills, and achievements.


Future Improvements

Planned enhancements include:
  - Additional project case studies.
  - Dark and light theme support.
  - Interactive data visualisations.
  - Performance optimisation.
  - Continuous accessibility improvements.
